-------------------------------------------------------------------------------
 INVARIANTS (every phase must uphold these — a phase that violates one is a fail)
-------------------------------------------------------------------------------
 I1. Source on disk is authoritative; all indices remain fully rebuildable.
 I2. Single-repo indexing is UNCHANGED. Cross-repo work is post-processing only.
 I3. Query latency stays bounded; federated traversal is depth + hop-budget capped.
 I4. Pure Rust, #![forbid(unsafe_code)]. No mandatory external daemons/toolchains.
 I5. SCIP/LSP are OPTIONAL accelerators, never required to index a repo.
 I6. Every mechanism is language-agnostic and works across corpora.

-------------------------------------------------------------------------------
 ORCHESTRATION PROTOCOL (read this first — governs how phases are executed)
-------------------------------------------------------------------------------
 The MAIN AGENT owns this file and the loop. For each phase, in order:

   1. DISPATCH: invoke a subagent (general-task-execution) with:
        - the phase's Goal, Scope (files), Steps, and Acceptance Criteria (verbatim),
        - the INVARIANTS block above,
        - instruction to NOT proceed past its phase and to report back a summary
          of files changed, commands run, and acceptance-criteria results.
   2. CHECK WORK: when the subagent reports, the main agent independently verifies:
        - run `cargo build` (workspace) and `cargo test -p <touched crates>`,
        - read the key changed files to confirm the criteria are actually met
          (do not trust the report alone),
        - confirm no invariant was violated.
   3. MARK: edit this file — set the phase status [ ]->[x] (or [!] if blocked),
      fill the "Result:" line with a one-line outcome + commit ref if any.
   4. GATE: only dispatch the next phase if the current phase is [x] and green.
      If [!], stop and surface the blocker to the user.

 Each phase is designed to leave the workspace compiling and tests green.
 Phases are additive; do not break existing cross-corpus doc-frontmatter linking.
